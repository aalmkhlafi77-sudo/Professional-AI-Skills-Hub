# Professional AI Skills Hub

**مكتبة مهارات احترافية لوكلاء الذكاء الاصطناعي، مبنية على مراجعة الجودة والأمان قبل الاعتماد.**

A curated, security-first collection of reusable AI-agent skills for code quality, web UI, testing, deployment and data integrity.

## ما الذي ستجده هنا؟

- **14 مهارة داخلية** في [`skills/`](skills/) تشمل مراجعة React، الواجهات المتجاوبة، GSAP، أمن PHP/MySQL، قواعد البيانات، اختبارات المتصفح، النسخ الاحتياطي وجودة طلبات السحب.
- **مصادر خارجية قيد التقييم** في `candidates/` و`intake/`. وجودها هنا لا يعني اعتمادها أو تثبيتها.
- **معايير قبول موثقة** في [سياسة الاعتماد](docs/ADMISSION_POLICY.md)، مع تقارير الأدلة في `docs/reviews/`.
- **أدوات فحص واختبارات** للمراجعة دون منح الثقة تلقائيًا لأي كود خارجي.

## التثبيت

لتجهيز ملفات ZIP مستقلة للمهارات الداخلية، استخدم [GitHub Actions — Package first-party ChatGPT skills](.github/workflows/package-chatgpt-skills.yml)، ثم نزّل ملف artifact بعد نجاح التشغيل.

لتثبيت مهارة واحدة في ChatGPT، ارفع ملف ZIP الخاص بها من صفحة المهارات. لتثبيت المهارات في Codex، انقل مجلد المهارة الذي يحتوي على `SKILL.md` إلى مسار المهارات المعتمد في بيئتك.

**لا تُثبّت مجلدات `candidates/` أو `intake/` على أنها مهارات معتمدة.**

## سياسة الجودة

الاعتماد الرسمي للمصادر الخارجية يشترط درجة لا تقل عن **90/100**، اجتياز جميع بوابات الأمان والاختبارات المطلوبة، ومراجعة بشرية محددة. الفحص الثابت وحده لا يثبت الأمان أو الجودة التشغيلية.

## هيكل المستودع

| المسار | الغرض |
|---|---|
| `skills/` | مهارات داخلية متاحة |
| `candidates/` | مرشحات خارجية غير معتمدة |
| `intake/` | مواد ومصادر قيد التقييم |
| `catalog/` | سجلات المرشحين والاعتمادات |
| `docs/` | السياسات والتقارير |
| `tests/` | اختبارات قواعد المستودع |

## التحقق المحلي

```bash
python3 scripts/validate_catalog.py
python3 -m unittest discover -s tests -v
```

الاختبارات المذكورة لا تعني اعتمادًا أمنيًا للمحتوى الخارجي.

## الترخيص

المحتوى الأصلي للمستودع تحت رخصة MIT؛ وتبقى تراخيص المواد الخارجية مستقلة.
