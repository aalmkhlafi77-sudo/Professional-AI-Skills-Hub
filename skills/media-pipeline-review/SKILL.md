# Media Pipeline Review

1. Trace file selection, validation, upload, storage, database reference, public URL and subsequent retrieval.
2. Check MIME, dimensions, duration, encoding/container compatibility, range requests and cache headers.
3. Investigate poster-first flicker, preload strategy, aspect-ratio cropping and fallback behavior on mobile.
4. Separate source-file quality, network latency, server configuration and browser decoding hypotheses.
5. Recommend minimally invasive fixes and objective browser tests; do not replace media or modify hosting without approval.

This is an original instruction-only skill. It includes no scripts, executables, dependencies or network installation steps.
