# Responsive UI Audit

1. Inventory key screens and approved design constraints; record device widths, DPR, browser and RTL mode.
2. Check overflow, text overlap, safe areas, touch targets, sticky navigation, focus states, reduced motion and contrast.
3. Review hero image/video crop, aspect ratios, loading placeholders and layout shifts without altering original media.
4. Separate screenshot-based observations from browser-reproduced issues and code hypotheses.
5. Provide viewport-specific acceptance criteria and minimal-diff corrections; do not edit or deploy without approval.

This original skill is instruction-only and includes no executable scripts, network hooks or third-party dependencies. Consult `references/PROVENANCE.md` for source-review limits.
